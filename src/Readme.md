# 🎓 College Timetable Planner

A full-stack web application for managing and viewing college class schedules.

## 🚀 Project Overview

College Timetable Planner allows students to view their weekly class schedule in a clean and interactive interface.

The application will provide features such as:

- Weekly timetable
- Day-wise schedule
- Subject information
- Teacher information
- Classroom information
- Search and filtering
- Add, edit and delete classes
- Responsive design

## 🛠️ Technology Stack

### Frontend
- React.js
- Vite
- CSS
- React Hooks

### Backend
- Node.js
- Express.js

### Database
- MongoDB
